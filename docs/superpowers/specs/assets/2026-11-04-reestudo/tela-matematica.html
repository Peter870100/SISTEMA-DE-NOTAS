O que é razão

Razão é a comparação entre dois números por meio de uma divisão. Se uma turma tem 12 meninas e 18 meninos, a razão de meninas para meninos é 12/18, que simplificada dá 2/3. Ou seja: para cada 2 meninas, há 3 meninos.

O que é proporção

Proporção é a igualdade entre duas razões: a/b = c/d. A propriedade que resolve quase toda questão é a multiplicação cruzada: a · d = b · c.

Exemplo resolvido

Uma receita usa 3 xícaras de farinha para 2 de leite. Quantas xícaras de leite são necessárias para 12 de farinha?

3/2 = 12/x → 3 · x = 2 · 12 → x = 8

São necessárias 8 xícaras de leite.

Pegadinhas comuns de prova

  • A ordem importa: a razão de A para B não é a mesma de B para A.
  • Mesma unidade: 30 minutos para 2 horas é 30/120 = 1/4, e não 30/2.
  • Grandezas inversas: com o dobro de pedreiros, o tempo cai pela metade. Aí a conta direta não vale.
